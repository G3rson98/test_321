# environments
Ambientes destino DeltaX, usuarios de prueba (solo secret_ref) y parámetros administrativos — RF-AMB-01, RF-AMB-02, RF-EJE-04.
Rutas (ver `ROUTES` de @katalyst/shared): GET /api/v1/environments, POST /api/v1/environments, GET /api/v1/environments/:id, PUT /api/v1/environments/:id, GET /api/v1/environments/:id/users, POST /api/v1/environments/:id/users, PUT /api/v1/environments/:id/users/:userId, GET /api/v1/settings/runtime, PUT /api/v1/settings/runtime.

# devices
Flujo de dispositivo (código de un solo uso, aprobación en el panel, credencial revocable) y estado del asistente — RF-GRB-01.
Rutas (ver `ROUTES` de @katalyst/shared): POST /api/v1/devices/authorize, POST /api/v1/devices/token, GET /api/v1/devices/authorizations/:userCode, POST /api/v1/devices/approve, POST /api/v1/devices/deny, GET /api/v1/devices, DELETE /api/v1/devices/:id, GET /api/v1/devices/status, POST /api/v1/devices/heartbeat.
